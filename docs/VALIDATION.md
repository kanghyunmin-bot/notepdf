# v1.0.0-rc.1 검증 범위

검증일: 2026-10-12. 실제 실행, 빌드 검사, 아직 하지 않은 검사를 구분합니다.

## Android

- Android 15 / API 35 ARM64 에뮬레이터에서 서명된 배포 APK 설치·실행 성공.
- 실제 Samsung Notes 형식 fixture 두 개: 삽입 PDF 21페이지, 필기 3페이지 변환 성공.
- Android PDF 렌더러로 변환 결과를 열고 빈 페이지가 아닌 것을 확인.
- 앱의 읽기 전용 PDF provider를 통한 내보내기 성공. 내보낸 필기 PDF는 3페이지, 벡터 곡선 명령 1,557,962개를 포함함.
- 잘못된 입력 거부, 변환 취소, 오류·취소 후 재변환 성공.
- 앱 프로세스 종료 후 재실행 시 완성 PDF와 기록 복원 성공.
- 가로 방향의 700dp 이상 레이아웃 실행 확인. 실제 Samsung One UI 태블릿과 동일한 환경은 아님.
- APK v2/v3 서명, 16KB ZIP 정렬 검사 통과. ELF LOAD 세그먼트 정렬 `0x4000` 확인. 실제 16KB 페이지 기기 실행은 미검증.
- INTERNET / 전체 파일 접근 권한 없음. foreground service, dataSync, 알림 표시 권한만 선언.

아직 확인하지 않은 것: 실제 갤럭시 탭, One UI의 공유 시트·배터리 관리, 시스템 저장창 전체 사용자 동선, 다른 Android 버전, 모든 Samsung Notes 펜·이미지·텍스트 형식. API 26은 빌드 최소 버전이며 실제 API 26 기기 실행 검증을 뜻하지 않음.

## macOS

- Apple Silicon 개발 Mac에서 앱 실행, 파일 선택, 21페이지/3페이지 실제 변환, PDF 미리보기 확인.
- 변환 코어 테스트: 원본 보존, 같은 이름 파일 보호, 경고 전달, 유효하지 않은 PDF 거부, 오류 전달, 취소, 제한 시간, 임시 파일 정리 통과.
- ad-hoc 코드 서명 검증 통과. Apple Developer ID 서명·공증 또는 다른 Mac에서의 설치 검증을 뜻하지 않음.

실제 노트 fixture, 결과 PDF, 화면 캡처는 개인 자료를 포함할 수 있으므로 저장소·공개 소스 ZIP·배포 앱에서 제외했습니다.
